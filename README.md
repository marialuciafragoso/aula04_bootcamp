# Funcoes_Estrutura-de-dados

Aprofundamento em Python com foco em funções, tipagem e estruturas de dados complexas — construindo código mais organizado, legível e reutilizável.

## Conteúdo

- **Funções** — criação, separação de responsabilidades e reuso de código
- **Type Hints** — anotações de tipo com `str`, `float`, `dict`, `None` e `-> tipo`
- **Tipos Complexos** — entendendo as diferenças entre dicionários, listas, tabelas CSV, DataFrames e planilhas Excel
- **Importação de módulos** — organizando o projeto em múltiplos arquivos e importando funções entre eles
- **Leitura de arquivos CSV** — usando `csv.DictReader` para transformar cada linha em um dicionário
- **Validação de entrada** — combinando `while True`, `try-except` e `if` para garantir dados corretos

## Exercícios

- Manipulação de listas: iteração, remoção e adição de elementos
- Operações com dicionários: criação, acesso e contagem de caracteres
- Leitura e exibição de dados de um arquivo CSV real
- Cadastro de múltiplos funcionários em loop com dicionários

## Desafio — Gerador de Bônus 2.0

Refatoração completa do desafio anterior: o programa foi dividido em funções independentes com type hints, cada uma responsável por uma etapa do fluxo — coleta de nome, salário e bônus, cálculo do valor final e exibição do resultado. As funções foram separadas em módulos distintos e importadas entre arquivos, simulando uma estrutura de projeto real.

## Tecnologias

- Python 3.11
